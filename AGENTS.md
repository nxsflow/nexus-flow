# Agent Instructions

## The software factory

Work in this repository follows the software factory. Before any work, read `factory/FACTORY.md`, `factory/CONFIG.md` and `factory/GENESIS.md`, and the index of the decisions in force (`cargo xtask decisions --current --index`). A pm session reads `factory/roles/pm.md`, a coding session `factory/roles/coder.md`.

GENESIS.md describes the product's target state; FACTORY.md and CONFIG.md describe how work moves here today. The project's durable rules are decisions in force in `factory/decisions/`: read in full the ones your work touches (`--ticket`, `--topic`).
