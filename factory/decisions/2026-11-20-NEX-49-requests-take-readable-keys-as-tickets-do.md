# 2026-11-20 · NEX-49 · Requests take readable keys as tickets do

- Decided by: Carsten
- Why: one readable form for tickets and requests, already decided in RFC 0002: the creating member's tag in the coordination space, a dot and a number, such as `ka.7`, written once. Written into RFC 0009, "Request ids".
- Instead of: the object id alone, accepted by a unique prefix as git accepts a short commit hash.
- Topics: cross-repo, coordination, requests, ids
