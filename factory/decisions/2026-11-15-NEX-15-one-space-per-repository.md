# 2026-11-15 · NEX-15 · One NoCentralDB space per repository holds its tickets, decisions and status notes

- Decided by: Carsten
- Why: decisions and status notes point at tickets all the time, and a NoCentralDB link only reaches objects in the same space; finer rights can come later as small extra spaces. Goals and requests live in a coordination space per group of repositories (GENESIS.md).
- Instead of: a space per module per repository, where every cross-module reference becomes an id that can dangle.
- Topics: nocentraldb, spaces, storage
