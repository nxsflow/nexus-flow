# 2026-11-20 · NEX-45 · A request is addressed to a repository and read by its pm

- Decided by: Carsten
- Why: pms are replaced and each is a new member, so a request addressed to a member id would be lost; a question for the owner goes into a needs-owner ticket, not a second inbox. Written into RFC 0009, "Addressed to a repository".
- Instead of: a request that may also be addressed to a person, such as the owner, through a record of its own beside the repositories.
- Topics: cross-repo, coordination, requests
