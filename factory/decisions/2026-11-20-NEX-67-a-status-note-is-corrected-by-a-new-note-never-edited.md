# 2026-11-20 · NEX-67 · A status note is corrected by a new note for the same day that names it, never edited in place

- Decided by: Carsten
- Why: a note is what the owner was told that day, and nothing is lost silently (GENESIS.md, principle 4; RFC 0007, "Correcting a note"). Answer (a) in NEX-67.
- Instead of: editing a note in place, or editing it until the next note is written.
- Topics: status, append-only
