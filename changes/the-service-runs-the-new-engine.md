[en]
The background service now runs channels declared `engine: v2`: on every tick it steps the open runs of each registered workspace that has one, starts their sessions, and keeps the machine awake while one of them works. A workspace that never ran on the new engine costs the service one file check. The new engine is still being built and is not ready for general use. A run on the new engine works in its own clone beside the workspace, `<workspace>-v2`; from that directory the old engine starts nothing: `nxc send`, `nxc reply` and `nxc withdraw` on the old engine are refused before anything is written, every other command that would start a session there starts none, and each refusal names the workspace's own directory to run it from. Reads, `nxc status` and the new engine's own commands work from there, with the workspace's declarations.
[de]
Der Hintergrunddienst führt jetzt Kanäle aus, die `engine: v2` deklarieren: Bei jedem Takt treibt er die offenen Läufe jedes registrierten Arbeitsbereichs voran, der welche hat, startet ihre Sitzungen und hält den Rechner wach, solange eine davon arbeitet. Ein Arbeitsbereich, der nie auf der neuen Engine lief, kostet den Dienst eine Dateiprüfung. Die neue Engine entsteht noch und ist nicht für den allgemeinen Gebrauch bereit. Ein Lauf auf der neuen Engine arbeitet in einem eigenen Klon neben dem Arbeitsbereich, `<arbeitsbereich>-v2`; aus diesem Verzeichnis startet die alte Engine nichts: `nxc send`, `nxc reply` und `nxc withdraw` auf der alten Engine werden abgelehnt, bevor etwas geschrieben wird, jeder andere Befehl, der dort eine Sitzung starten würde, startet keine, und jede Ablehnung nennt das eigene Verzeichnis des Arbeitsbereichs, aus dem er auszuführen ist. Lesebefehle, `nxc status` und die eigenen Befehle der neuen Engine funktionieren von dort, mit den Deklarationen des Arbeitsbereichs.
