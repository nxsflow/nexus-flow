[en]
The contracts of the rebuilt run engine are frozen as v1, after the reviews by manufakt.io and app-foundations. A reader now keeps every enum value it does not know instead of refusing the object, run status separates what folds from the log from what only the machine holding the run can say, status names the key an answer takes, every run carries an opaque tenant, and a hold on a usage limit with a named reset no longer counts toward the hold limit. Nothing runs on this engine yet.
[de]
Die Verträge der neu gebauten Run-Engine sind nach den Reviews von manufakt.io und app-foundations als v1 eingefroren. Ein Leser behält jetzt jeden Enum-Wert, den er nicht kennt, statt das Objekt abzulehnen; der Run-Status trennt, was aus dem Log folgt, von dem, was nur die Maschine sagen kann, die den Run hält; der Status nennt den Schlüssel, den eine Antwort braucht; jeder Run trägt einen opaken Tenant; und ein Hold auf ein Nutzungslimit mit genanntem Reset zählt nicht mehr gegen das Hold-Limit. Auf dieser Engine läuft noch nichts.
