[en]
**The release notes answer "does this change the library contract?".** Every entry that touches a consumed surface carries an explicit `facade:` verdict — `changed` or `breaking` — and the notes render a dedicated Facade Contract section for it. An embedding consumer can decide re-review versus fast-track from the feed instead of from a diff.
[de]
