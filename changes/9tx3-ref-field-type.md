[en]
A plugin can declare a custom field of type `ref`: a typed reference to another item (`targets` names the item types it may point at), single or a list. `--set <field>=<id>` and `nxf entry add` validate the target — it must exist, not be deleted, and have an allowed type; a closed or archived item is fine; a bare local id is resolved. `nxf schema --json` reports `kind: "ref"` and `targets`; `show --json` adds `refs`, resolving each target or marking it `found: false`; the human `show` prints each target's id and title. A ref is written with the ordinary field ops: no fold revision moves, and a replica started from a snapshot stays valid. Library: `FieldType::Ref`, `FieldDecl::targets`, `SchemaField::targets`, `read::ref_targets` / `RefTarget`, `write::resolve_ref_input` / `resolve_ref_sets`, `Store::referenced_by_bulk`, `model::is_valid_ref_value`, `model::ref_place_ok`.
[de]
Ein Plugin kann ein eigenes Feld vom Typ `ref` deklarieren: einen typisierten Verweis auf ein anderes Item (`targets` nennt die erlaubten Item-Typen), einzeln oder als Liste. `--set <feld>=<id>` und `nxf entry add` prüfen das Ziel — es muss existieren, darf nicht gelöscht sein und muss einen erlaubten Typ haben; geschlossene oder archivierte Items sind erlaubt; eine nackte lokale Id wird aufgelöst. `nxf schema --json` meldet `kind: "ref"` und `targets`; `show --json` bekommt `refs`, das jedes Ziel auflöst oder mit `found: false` markiert; das menschenlesbare `show` zeigt Id und Titel jedes Ziels. Ein Verweis wird mit den gewöhnlichen Feld-Ops geschrieben: keine Fold-Revision bewegt sich, und eine aus einem Snapshot gestartete Replik bleibt gültig. Bibliothek: `FieldType::Ref`, `FieldDecl::targets`, `SchemaField::targets`, `read::ref_targets` / `RefTarget`, `write::resolve_ref_input` / `resolve_ref_sets`, `Store::referenced_by_bulk`, `model::is_valid_ref_value`, `model::ref_place_ok`.
