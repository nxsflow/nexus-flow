type: added

[en]
A channel can now declare `engine: v2` to run its commissions on the new run engine, which is being built and is not ready for general use. `nxc send --to <channel>` from the terminal opens such a run and prints its thread id at once; nothing is posted into the thread until the background service picks the run up, and the receipt says when no service attends the workspace. Its `await` block tells you to poll `nxc status --thread <id> --json` until `open` is 0. A persona cannot commission a channel on the new engine yet: `nxc list` leaves such channels out of a persona's directory, and a persona's send to one is refused with what to do instead. A session that the new engine started cannot send at all, and asks for what it needs with `nxc reply --escalate`. For a host embedding `nexus-chat`: `SendToReceipt::message_id` is now `Option<String>` (`None` only for a channel on the new engine; every other send fills it as before), `awaiting::DoneWhen` and `awaiting::StoppedWhen` become enums whose `Thread` variant is the old shape, `Await` gains `answer_in`, `ChannelDecl` gains `engine`, and `model::Refs` gains `run_key`. The JSON of every existing receipt is unchanged.
[de]
Ein Kanal kann jetzt `engine: v2` deklarieren, damit seine Aufträge auf der neuen Run-Engine laufen, die gerade entsteht und noch nicht für den allgemeinen Gebrauch bereit ist. `nxc send --to <kanal>` vom Terminal eröffnet einen solchen Lauf und gibt sofort seine Thread-ID aus; in den Thread wird erst etwas geschrieben, wenn der Hintergrunddienst den Lauf aufnimmt, und die Quittung sagt, wenn kein Dienst den Arbeitsbereich betreut. Ihr `await`-Block sagt, `nxc status --thread <id> --json` abzufragen, bis `open` 0 ist. Eine Persona kann einen Kanal auf der neuen Engine noch nicht beauftragen: `nxc list` lässt solche Kanäle aus dem Verzeichnis einer Persona weg, und ihr Senden an einen davon wird abgelehnt, mit dem, was sie stattdessen tun kann. Eine Sitzung, die die neue Engine gestartet hat, kann gar nicht senden und fragt nach dem, was sie braucht, mit `nxc reply --escalate`. Für einen Host, der `nexus-chat` einbettet: `SendToReceipt::message_id` ist jetzt `Option<String>` (`None` nur für einen Kanal auf der neuen Engine; jedes andere Senden füllt es wie bisher), `awaiting::DoneWhen` und `awaiting::StoppedWhen` werden Enums, deren Variante `Thread` die bisherige Form ist, `Await` bekommt `answer_in`, `ChannelDecl` bekommt `engine`, und `model::Refs` bekommt `run_key`. Das JSON jeder bestehenden Quittung bleibt unverändert.
