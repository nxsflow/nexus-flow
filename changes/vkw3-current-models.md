[en]
Personas now run on the current Claude models, and a fourth, lowest seniority level `intern` runs on Haiku. The seniority levels map to `claude-haiku-5-5` (`intern`, new), `claude-sonnet-5-5` (`junior`), `claude-opus-5-5` (`senior`) and `claude-fable-5-1` (`principal`), and a persona that declares `model: haiku`, as well as thread naming, uses `claude-haiku-5-5`. Before, the levels named the bare aliases `claude-sonnet-5`, `claude-opus-5` and `claude-fable-5`, and Haiku was pinned to `claude-haiku-4-5-20251001`.
