[en]
Security: the SQLite that `nxs` and `nxf-relay` bundle is now 3.54 (rusqlite 0.41, libsqlite3-sys 0.39), which fixes RUSTSEC-2026-0459 (CVE-2026-119375) in the bundled C library, and `nxs mcp serve` now runs on rmcp 3.9, which fixes RUSTSEC-2026-0462. Nothing changes in how a workspace database is opened or written (WAL, busy timeout, pragmas). Over MCP, a host that asks for a protocol version it knows still gets that version; a host that asks for one the server does not know gets 2025-11-25, the newest version with an `initialize` handshake, as before. For embedding apps: `nexus-chat` and `nexus-memory` expose `rusqlite` types in public signatures (`ChatStore::connection` and `MemoryStore::connection` return a `&rusqlite::Connection`; `ChatStore::open`, `MemoryStore::open` and others return `rusqlite::Result`), so an app that names those types, or links its own `libsqlite3-sys`, must move to rusqlite 0.41 / libsqlite3-sys 0.39 with this release.
[de]
Sicherheit: Das SQLite, das `nxs` und `nxf-relay` mitbringen, ist jetzt 3.54 (rusqlite 0.41, libsqlite3-sys 0.39); das behebt RUSTSEC-2026-0459 (CVE-2026-119375) in der mitgelieferten C-Bibliothek. `nxs mcp serve` läuft jetzt auf rmcp 3.9, das behebt RUSTSEC-2026-0462. Wie eine Workspace-Datenbank geöffnet und geschrieben wird (WAL, Busy-Timeout, Pragmas), ändert sich nicht. Über MCP bekommt ein Host, der eine ihm bekannte Protokollversion verlangt, weiterhin genau diese; verlangt er eine, die der Server nicht kennt, bekommt er wie bisher 2025-11-25, die neueste Version mit `initialize`-Handshake. Für einbettende Apps: `nexus-chat` und `nexus-memory` zeigen `rusqlite`-Typen in öffentlichen Signaturen (`ChatStore::connection` und `MemoryStore::connection` liefern eine `&rusqlite::Connection`; `ChatStore::open`, `MemoryStore::open` und weitere liefern `rusqlite::Result`); eine App, die diese Typen benennt oder ein eigenes `libsqlite3-sys` linkt, muss mit diesem Release auf rusqlite 0.41 / libsqlite3-sys 0.39 wechseln.
