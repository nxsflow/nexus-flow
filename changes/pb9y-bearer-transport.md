[en]
Sync library (`nxs-sync`): `HttpTransport::with_bearer(token)` makes a transport that sends `Authorization: Bearer <token>` on every relay route (pull, push, register, presence, and the snapshot anchor check). It shares the base transport's connection pool, replaces a Basic credential taken from the URL, keeps the token out of every error and `Debug` output, and carries it on same-host redirects only. When a relay answers 401 or 403, every route now returns a typed refusal: `TransportError::refused(status)`, with `is_refused()`/`refused_status()` on `TransportError`, `SyncError` and `SnapshotError`. The refusal is never retried. For existing Basic callers, a 401/403 error now reads "the relay refused this request's credential (HTTP 401)" instead of naming the URL and its status code.
[de]
Sync-Bibliothek (`nxs-sync`): `HttpTransport::with_bearer(token)` erzeugt einen Transport, der auf jeder Relay-Route `Authorization: Bearer <token>` sendet (Pull, Push, Registrierung, Präsenz und die Anker-Prüfung eines Snapshots). Er teilt den Verbindungspool des Basis-Transports, ersetzt eine Basic-Anmeldung aus der URL, hält das Token aus jeder Fehler- und `Debug`-Ausgabe heraus und gibt es bei Weiterleitungen nur an denselben Host weiter. Antwortet ein Relay mit 401 oder 403, liefert jede Route jetzt eine typisierte Ablehnung: `TransportError::refused(status)`, mit `is_refused()`/`refused_status()` an `TransportError`, `SyncError` und `SnapshotError`. Eine Ablehnung wird nie wiederholt. Für bestehende Basic-Aufrufer lautet ein 401/403-Fehler jetzt "the relay refused this request's credential (HTTP 401)", statt URL und Statuscode zu nennen.
